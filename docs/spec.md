# 老房 3D 模型展示工具 - 产品需求文档 (PRD)

---

## 1. 项目概述

**产品名称**：老房 3D 可视化工具
**版本**：v1.0
**目标**：为中国传统风格老房提供直观的 3D 交互模型，帮助用户（房主、设计师、施工方）理解空间结构、方位关系及改造方案。当前阶段为技术 demo，后续将增加内部家具布置功能。

**风格定位**：中国传统建筑风格（白墙黛瓦、木格窗、深木色门）。

---

## 2. 用户角色与使用场景

| 角色 | 场景 |
|------|------|
| 房主（您） | 查看房屋整体外观、内部布局，验证改造设计，与设计师沟通 |
| 设计师 | 展示方案，标注区域，进行空间推演 |
| 施工方 | 了解建筑结构（屋顶、山墙、阁楼），指导施工定位 |

---

## 3. 建筑结构

### 3.1 空间布局

A、B、C 三个区域沿西南→东北方向**线性排列**，宽度统一为 2.56m：

```
俯视示意图（默认镜头视角：站在西南门口望向东北方向）

                     东北(远) ──→ 建筑最里端
               ┌──────────────────┐
               │       后窗       │
               │   ┌──────────┐   │
      过道     │   │  C区阁楼  │   │  邻居
      (西北)   │[窗C] 2.55m  │   │ (东南)
      左侧     │   ├──────────┤   │  右侧
               │[窗B]  B区主屋 │   │
               │   │  双坡屋顶  │   │
               │   │  3.0m    │   │
               │   ├──────────┤   │
               │   │  A区天台  │   │
               │   │  平顶     │   │
               │   │  2.9m    │   │
               │   └──────────┘   │
               │     入户门       │
               └──────────────────┘
                     西南(近)
                 相机位置 (门外~3m)
```

### 3.2 各区域规格

| 区域 | 位置 | 长(m) | 宽(m) | 屋顶 | 高度参数 | 附属结构 |
|------|------|-------|-------|------|---------|---------|
| A区 | 西南端 | 2.9 | 2.56 | 平顶（露天小天台） | 墙体高 3.15m | 入户门（西南面，深木色传统木门），天台围栏（青砖色矮墙，高约 0.9m） |
| B区 | 中间 | 3.0 | 2.56 | 双坡屋顶（与C区共用） | 檐口 3.15m，脊高 5m | 过道侧窗 ×1（西北面），山墙（左右两侧三角形封顶） |
| C区 | 东北端（B区最里端） | 2.55 | 2.56 | 同上（B+C 共用屋顶） | 檐口 3.15m，脊高 5m，阁楼底板高 2.15m | 过道侧窗 ×1（西北面），后窗 ×1（东北面），阁楼楼板/支柱/爬梯示意 |

### 3.3 关键结构关系

- 双坡屋顶覆盖 B 区和 C 区整体（总长 5.55m），坡面朝向西南/东北
- 山墙位于 B+C 区左右两侧（西南侧和东北侧），三角形封顶
- C区是 B区的功能子区域（阁楼区），在 B区最里端
- A区独立，平顶天台，与 B区共墙

### 3.4 方位关系

| 方向 | 要素 |
|------|------|
| 西南 | 建筑正面，A区入户门（相机初始位置在此方向约 3m 外） |
| 东北 | 建筑背面，C区后窗（建筑最里端） |
| 西北 | 过道（宽 1.5m，红砖地面），B/C区窗户朝向此面 |
| 东南 | 邻居墙体（半透明体块示意） |

### 4.3 光照方案

| 光源 | 颜色 | 强度 | 方向/说明 |
|------|------|------|----------|

## 5. 核心功能需求

### 5.1 3D 模型展示

- 展示建筑主体，包含 A、B、C 三个区域，尺寸比例准确（详见 §3.2）。
- 显示双坡屋顶（覆盖 B+C 区，脊高 5m，坡面朝向西南/东北）、山墙（B+C 区左右两侧，三角形封顶）、A区入户门（深木色传统双开门）、窗户（×3，过道侧 2 个 + 背面 1 个，木格栅样式）、阁楼结构（楼板、支柱、爬梯示意）。
- 显示周边环境：过道（西北侧，宽 1.5m，红砖地面）、邻居（东南侧，半透明体块）。

### 5.2 交互控制

**桌面端**

| 操作 | 行为 |
|------|------|
| 鼠标左键拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| 鼠标中键拖拽（或 Shift+左键） | 平移 |

**移动端**

| 操作 | 行为 |
|------|------|
| 单指滑动 | 旋转视角 |
| 双指 pinch | 缩放 |
| 双指平行拖拽 | 平移 |

### 5.3 信息标注

- **区域标签**：A区、B区、C区（半透明背景，清晰可见）。
- **方向标识**：地面固定标注 N/S/E/W（世界方向），帮助定位。
- **入口标识**：🚪 符号标示入户门位置（西南面）。

### 5.4 辅助工具

- **罗盘**：右上角 2D 覆盖层，动态罗盘，随视角旋转，指示当前相机朝向的方位（N/E/S/W）。

### 5.5 初始视角与加载

- 加载时显示 Loading 占位（灰色背景 + "加载中..."）。
- 场景就绪后淡入，相机默认位于西南方向入口外约 3m，高度 2.5m，看向入户门，展示建筑正面全貌。

## 6. 技术架构

### 6.1 技术栈

| 层面 | 选型 | 理由 |
|------|------|------|
| 框架 | React 18 + TypeScript | 后续加家具布置需要组件化状态管理 |
| 3D 引擎 | Three.js（原生） | 场景适中，原生控制更直接 |
| 构建工具 | Vite | 轻量快速，适合 demo 迭代 |
| 样式 | Tailwind CSS | 用于 2D UI 覆盖层（罗盘、提示等） |

### 6.2 组件树

```
App
├── Scene3D          // Three.js 场景容器（canvas）
│   ├── House        // 主建筑模型（A/B/C区 + 屋顶 + 门窗）
│   ├── Environment  // 过道、地面、邻居体块
│   └── Labels       // 区域标签、方向标识、入口标识（3D 标注）
├── Compass          // 右上角动态罗盘（2D overlay）
└── LoadingScreen    // 初始加载状态
```

### 6.3 核心模块（非组件，纯逻辑）

| 模块 | 职责 |
|------|------|
| `config/house` | 所有尺寸、颜色、位置参数集中配置 |
| `builders/` | 程序化生成墙体、屋顶、门窗的 Three.js 几何体 |
| `controls/` | OrbitControls 封装（桌面+移动端适配） |
| `materials/` | 材质工厂（白墙、瓦片、木纹、红砖等） |

### 6.4 参数配置原则

- 所有尺寸、颜色、位置参数集中在 `config/` 目录下，以常量对象导出。
- 修改参数后刷新即可看到变化，无需深入业务代码。
- 材质参数与几何参数分离管理。

### 6.5 部署

- **托管平台**：GitHub Pages
- **CI/CD**：GitHub Actions，推送 `main` 分支自动构建并部署
- **构建产物**：Vite 输出静态文件至 `dist/`，部署到 GitHub Pages
- **访问方式**：通过 `https://<username>.github.io/<repo>` 直接访问

## 7. 非功能需求

| 需求 | 说明 |
|------|------|
| 性能 | 模型总面数合理，60fps 流畅运行，支持主流 PC 及移动端浏览器 |
| 兼容性 | 支持 Chrome、Firefox、Edge、Safari 最新版本 |
| 加载速度 | 首次加载 < 3 秒（无外部纹理资源，所有材质程序生成） |
| 可维护性 | 代码模块化，尺寸、颜色、位置等参数集中配置，便于后续修改 |
| 扩展性 | 预留后续增加内部家具布置、标注点、测量工具等功能的接口 |
| WebGL 降级 | 检测到 WebGL 不可用时，显示明确提示信息 |

---

## 8. 边界与异常处理

| 情况 | 处理 |
|------|------|
| WebGL 不可用 | 显示"您的浏览器不支持 WebGL，请使用最新版 Chrome/Firefox/Edge/Safari" |
| 移动端竖屏 | 正常可用，无特殊限制 |
| 窗口缩放 | 场景自适应 resize，相机比例同步调整 |
| 低性能设备 | 降低几何体分段数（通过配置参数调整），保证 30fps 最低可接受帧率 |

---

## 9. 验收标准

1. 模型尺寸与本文档 §3.2 规格一致（误差 ≤ 5cm）。
2. 空间方位关系正确：A区西南端（入户门），C区东北端（后窗），过道西北侧，邻居东南侧。
3. 视觉风格符合中国传统建筑：白墙、深灰瓦顶、深木色门窗、木格窗纹理。
4. 交互操作流畅，桌面端（鼠标）和移动端（触摸）均无卡顿、闪烁。
5. 所有标签（A/B/C）、方向标识（N/S/E/W）、入口标识（🚪）位置正确且清晰。
6. 初始视角符合要求（入口外西南方向约 3m，高度 2.5m，正对入户门）。
7. 罗盘指针方向与地面 N/S/E/W 标记对应准确。
8. 代码可读性良好，关键逻辑有注释，配置参数集中管理。
9. WebGL 不可用时展示友好提示。
10. 第一人称漫游：点击入户门或按钮进入室内参观，WASD/箭头键移动+鼠标环顾，Esc 退出。
11. 手机端支持：虚拟摇杆移动+触摸环顾。
